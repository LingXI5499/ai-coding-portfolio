# 数据源与开源项目致谢

本项目没有复制下列项目源代码，但在设计、运行时数据或工程思路上参考/使用了公开资源：

- Hacker News Firebase API：技术新闻数据源。
- GitHub Trending：公开趋势页面。
- 百度热搜：公开热榜页面。
- 中国政府网：公开政策信息页面。
- `jiabaobei/xiaozhao-radar`：运行时读取其公开 `jobs.json` 作为 MVP 校招数据源；原项目为 Apache-2.0，使用时应保留其来源说明并遵守其许可。
- `sansan0/TrendRadar`、`newsnext/newsnow`、`dshuais/DailyHotApi`：用于前期架构调研与思路参考。

本项目的采集器仅面向公开信息，不提供验证码绕过、登录态窃取、访问控制规避等功能。第三方页面结构和服务条款可能变化，正式长期运行前应再次核对对应站点的使用规则。
